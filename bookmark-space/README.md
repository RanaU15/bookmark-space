# Bookmark Space — Chrome Extension

A local-first visual New Tab page that reads Chrome bookmarks and keeps the page synchronized with the browser.

## Requirements

- Node.js 20 or newer (Node 18.18+ may also work with compatible npm versions)
- Google Chrome or Chromium
- npm

## Install dependencies and build

```bash
npm install
npm run build
```

Vite writes the extension to `dist/`.

## Load into Chrome

1. Open `chrome://extensions`.
2. Turn on **Developer mode**.
3. Select **Load unpacked**.
4. Choose this project's `dist` folder.
5. Open a new tab. Bookmark Space should appear.

After changing source code, run `npm run build` again and press Reload on the extension card at `chrome://extensions`.

## Development

```bash
npm run dev
```

The Vite development page can preview the UI, but browser bookmarks are only available when the app is loaded as an installed extension. Build and load `dist` to test the real Chrome APIs.

## Bookmark synchronization

The New Tab page reads `chrome.bookmarks.getTree()` on load and listens for:
- `onCreated`
- `onRemoved`
- `onChanged`
- `onMoved`
- `onChildrenReordered`
- `onImportEnded`

It re-reads the tree after each event, so title, URL, folder and ordering changes are reflected without a server or database.

## Thumbnail and privacy notes

Website screenshots are generated by the WordPress mShots service:
`https://s.wordpress.com/mshots/v1/<encoded-url>?w=640`

This is a third-party service. The bookmarked URL is sent to it to generate a screenshot. The setting **Website thumbnails** can be switched off. If a screenshot fails, a generated fallback tile is shown. Favicons are fetched from Google's favicon service.

The browser's built-in favicon API is not exposed to extension pages in a way that reliably provides icons for arbitrary bookmark URLs, so this starter uses Google's public favicon endpoint. You can replace this with a privacy-preserving local icon strategy later.

## Permissions

- `bookmarks`: read bookmarks and subscribe to bookmark change events.
- `storage`: save theme and thumbnail preference.

No host permissions, background service worker, account, remote database, or analytics are used. The thumbnail and favicon image requests are remote image loads, not privileged API access.

## Notes / limitations

- Chrome's `chrome_url_overrides.newtab` replaces the New Tab page. It does not replace the address bar or browser bookmarks bar.
- Folder navigation includes all folders returned by Chrome, including the built-in bookmark folders.
- A screenshot provider may return a delayed preview, block some pages, or fail. The extension falls back to a branded letter tile.
- The extension does not create or delete browser bookmarks; it displays and navigates to them.
